# danielKB
This is a keyboard I made for myself. Since I like the HHKB Style, I have made some modifications based on HHKB Layout.



## Dev. Info
- MPU : STM32F103RCT6
- IDE : STM32CubeIDE 1.19
- ECAD : EasyEDA Pro 2.2.37
- PCB and PCBA were manufactured through JLCPCB( [jlcpcb.com](https://jlcpcb.com/) )



## Version

- Hardware : v 1.6.0
- Firmware : v 1.0.x 



## Description
 - Currently, Volume Up/Down and Mute key are operated.
   
 - It basically operates in NKRO mode, and can also be operated in 6KRO mode by changing the DIP Switch state.
   
 - The right Alt key can be changed to the IME key, depending on the dip switch setting on v 0.9.1.
